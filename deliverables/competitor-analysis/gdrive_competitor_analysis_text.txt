Competitor Analysis  
1. Why these 5 dimensions  
These dimensions cover the main steps between remembering a photo and actually finding it. A user can fail at any one 
of them. 
Dimension Why it matters 
Memory → Query Users may remember a situation, not exact search words. 
Clue Understanding The system needs to combine partial and uncertain clues. 
Candidate Discovery Useful candidates should appear even without an exact match. 
Search Refinement Users need help when the first search does not work. 
Result Evaluation The user still has to recognize the correct photo.

4. Google Photos: scope of improvement 
Google Photos is already strong at semantic photo understanding. The bigger opportunity is helping users when their own 
memory is incomplete or uncertain. 
Opportunity Possible improvement 
Starting query Turn a rough memory into useful clues. 
Uncertain clues Treat 'I think' or 'maybe' as soft signals. 
Failed search Suggest the next useful clue to add. 
Weak clues Combine several partial signals. 
Close match Use a similar photo as an anchor for the next search. 
Final check Show context that helps users recognize the photo. 
5. Connection to the business metric 
Successful retrieval can therefore be viewed as five linked stages: 
Stage Outcome 
Memory → Query User provides enough clues to start. 
Clue Understanding System interprets the clues. 
Candidate Discovery Relevant photos appear. 
Search Refinement User gets closer after a weak result. 
Result Evaluation User recognizes the intended photo.
