# Graduation Project: INDmoney SIP Retention

| Folder | What it is |
|---|---|
| [`ai-engine/`](ai-engine/README.md) | The AI Discovery Engine: scrapers, pipeline, research data and the Next.js 14 discovery dashboard. Run from inside this folder. |
| [`prototype/`](prototype/README.md) | SIP Steady, the MVP prototype (Next.js, mock data only), its docs, tests, `design-source/` and `clickable-prototype/`. |
| [`deliverables/`](deliverables/) | Submission assets: decks, PDFs, ZIPs, presentation material, competitor analysis, assignment brief. |

Each project has its own `package.json` and `node_modules`; run `npm` commands inside the project folder, not at the repository root.
